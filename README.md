# 🛠️ Sensor Enclosure & Mechanical Components (Casing)

This repository contains a collection of 3D-printable enclosures and mechanical components designed for various sensor modules and mechanical systems. These parts were developed using **PTC Creo Parametric**.

## 📁 Project Structure

The project is organized into three main modules:

### 1. 🌊 Turbidity Sensor Enclosure (`/Turbidity`)
Designed to house and protect turbidity sensors used in water quality monitoring.
*   **Key Features:** Threaded assembly (ulir) for secure fit, sensor mounting base, and protective cover.
*   **Files:** Includes `.stl` for 3D printing and `.prt`/`.asm` for CAD modification.
*   **Visuals:**
    ![Turbidity Case](Turbidity/Screenshot%202026-01-06%20235411.png)

### 2. 📏 Ultrasonic Sensor Casing (`/Ultrasonic_Casing`)
A custom mount and enclosure for HC-SR04 type ultrasonic sensors.
*   **Key Features:** Dual-bore front for sensor transducers, compact form factor, and mounting rails.
*   **Files:** `.stl` and `.prt`.
*   **Visuals:**
    ![Ultrasonic Case](Ultrasonic_Casing/Screenshot%202026-01-07%20000322.png)

### 3. 🧪 Stirrer Handle (`/Gagang_Pengaduk`)
Mechanical component for manual or automated stirring systems.
*   **Key Features:** Ergonomic design/compatible connector for stirring rods.
*   **Files:** `.stl` and `.prt`.
*   **Visuals:**
    ![Stirrer Handle](Gagang_Pengaduk/Screenshot%202026-01-07%20000107.png)

## 🚀 Getting Started

### Prerequisites
*   **For Printing:** Any 3D slicer (Cura, PrusaSlicer, etc.) and a 3D printer.
*   **For Modification:** PTC Creo Parametric (Educational Edition or Professional).

### Installation / Usage
1.  Clone this repository to your local machine.
2.  Navigate to the desired folder.
3.  Use the `.stl` files directly for 3D printing.
4.  Use the `.prt` or `.asm` files if you need to adjust dimensions or features.
